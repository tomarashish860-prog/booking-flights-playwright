AKQA SQA Automation Challenge – Booking.com Flight Search

Tech Stack: Playwright, JavaScript, Page Object Model (POM), HTML Report

Automation Coverage:

 One-way flight search
 Origin: DEL – Delhi International Airport
 Destination: BOM – Mumbai
 Runtime date selection: Today & Tomorrow
 Search submission validation
 Route and travel-date assertions after search
 Failure handling with Screenshot, Trace & Video

Objective:
Built a maintainable Playwright automation framework using POM with dynamic test data, assertions, reporting, and failure diagnostics.
